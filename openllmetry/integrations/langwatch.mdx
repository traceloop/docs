[LangWatch](https://langwatch.ai) is an [open source](https://github.com/langwatch/langwatch) LLM observability, evaluation and agent simulation platform.

LangWatch accepts OpenTelemetry traces over HTTP, so you can use OpenLLMetry to send your traces to LangWatch.

### Setup

Sign up for [LangWatch](https://app.langwatch.ai/) and get your API key from the project settings. Then set your environment variables:

```bash
TRACELOOP_BASE_URL="https://app.langwatch.ai/api/otel"
TRACELOOP_HEADERS="Authorization=Bearer%20<LANGWATCH_API_KEY>"
```

The SDK appends `/v1/traces` to the base URL, so traces are sent to `https://app.langwatch.ai/api/otel/v1/traces`.
If you self-host LangWatch, replace `https://app.langwatch.ai` with your own host.

You can then log traces with OpenLLMetry to LangWatch, here is an example:

```python
from openai import OpenAI
from traceloop.sdk import Traceloop

client = OpenAI()
Traceloop.init()

completion = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {
            "role": "user",
            "content": "Write a haiku about recursion in programming."
        }
    ]
)

print(completion.choices[0].message)
```

For more information check out the [LangWatch OpenTelemetry documentation](https://langwatch.ai/docs/integration/opentelemetry/guide).
